Entiendo perfectamente el problema: GitHub Pages sirve los ficheros tal cual, pero si una carpeta no tiene =index.html=, al visitarla por HTTP simplemente no hay nada que mostrar de forma "amigable" (o GitHub te redirige a la vista bruta del repo, no a un listado navegable).

La solución típica es generar un =index.html= autogenerado en cada carpeta de salida, con enlaces a su contenido. Se puede hacer fácil con el comando =tree -H= (genera un índice HTML con enlaces) o con un pequeño bucle en bash.

Como no veo el contenido exacto de tu script en este mensaje (aunque lo tengo en el contexto, indícame si quieres que lo cite literalmente para editarlo con precisión), te propongo la función genérica que añadirías:

#+begin_src bash
generar_index () {
    local carpeta="$1"
    local titulo="$2"
    (
        echo "<!DOCTYPE html><html><head><meta charset='utf-8'>"
        echo "<title>${titulo}</title></head><body>"
        echo "<h1>${titulo}</h1><ul>"
        for f in "$carpeta"/*; do
            nombre=$(basename "$f")
            echo "<li><a href=\"${nombre}\">${nombre}</a></li>"
        done
        echo "</ul></body></html>"
    ) > "$carpeta/index.html"
}
#+end_src

Notas sobre las opciones:
- =-H '.'= genera HTML con rutas relativas a partir de ese punto (importante: debe coincidir con la URL base real, normalmente basta con =.=).
- =-L 1= limita la profundidad a un nivel (evita listar subcarpetas si no quieres eso; quita esta opción si prefieres el árbol completo).
- =--noreport= omite la línea final con el resumen de "N directories, M files".
- =-o index.html= escribe la salida directamente al fichero, en vez de stdout.
- Debe ejecutarse /después/ de copiar/generar todos los ficheros definitivos en esa carpeta, y /antes/ del =git add=/=git commit= de la rama =gh-pages=.

*Qué añadir:*

#+begin_src bash
find CuadernosElectronicos -maxdepth 1 -name '*.ipynb' -exec cp {} "$DEST"/CuadernosElectronicos/ \;

# --- Índices navegables para las carpetas sin index.html propio ---
for carpeta in Transparencias Lecciones-html Lecciones-pdf \
               Practicas-html Practicas-pdf CuadernosElectronicos; do
    tree -H '.' -L 1 --noreport --charset utf-8 \
         -T "$carpeta" -o "$DEST/$carpeta/index.html" \
         "$DEST/$carpeta"
done

cp index.html "$DEST"/
#+end_src

Notas sobre las opciones que añadí respecto a lo que comenté antes:

- =-T "$carpeta"=: pone el nombre de la carpeta como título de la página (aparece en =<title>= y como encabezado).
- =-L 1=: solo primer nivel. *Importante:* en =Practicas-html= tienes subcarpetas (=guiones=, y una por cada práctica). Si quieres que el índice muestre también su contenido, cambia a =-L 2= solo para esa carpeta, o simplemente quita =-L 1= en todos para tener el árbol completo. Ejemplo si quieres tratar =Practicas-html= aparte:

#+begin_src bash
for carpeta in Transparencias Lecciones-html Lecciones-pdf Practicas-pdf CuadernosElectronicos; do
    tree -H '.' -L 1 --noreport --charset utf-8 \
         -T "$carpeta" -o "$DEST/$carpeta/index.html" \
         "$DEST/$carpeta"
done

tree -H '.' -L 2 --noreport --charset utf-8 \
     -T "Practicas-html" -o "$DEST/Practicas-html/index.html" \
     "$DEST/Practicas-html"
#+end_src

- El =-H '.'= hace que las rutas generadas sean relativas a la propia carpeta (correcto, porque el índice vive dentro de ella).

Con esto, cada carpeta enlazada en el README tendrá su =index.html= generado automáticamente en cada despliegue, así que al hacer clic verás un listado navegable en vez de los ficheros en bruto.
